# Birds & Bees Cafeto — website

Nature-themed, pure vegetarian cafe at Phooti Kothi Circle, Scheme 71, Indore.

- Table ordering (tables 1–10) → saved to Google Sheet → sent to WhatsApp 98260 33910
- Full in-cafe menu, gallery, reels, reservations, Google review button

## Update the menu
Edit the `MENU` list in `index.html` (search for `const MENU`). Prices are in ₹.

## Order backend
`apps-script-Code.gs` is a backup of the Google Apps Script. The live web-app URL is set in
`index.html` as `ORDER_ENDPOINT`.
